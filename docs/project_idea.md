# LudoLens Project Idea (MVP v1)

## Why this project exists
LudoLens is an open-source prototype to help everyday players, parents, and researchers explore game design patterns related to monetization pressure, time burden, and potential opacity.

## Who it serves
- Players: quickly compare games by a transparent scoring rubric.
- Parents: identify potential risk signals before allowing long-term play.
- Researchers: use a reproducible baseline for discussing game commercialization patterns.

## MVP assumptions
- Early-stage concept; data availability is still uncertain.
- Uses local handcrafted sample data only.
- Focuses on explainability over predictive sophistication.

## Scope in v1
- Local CSV ingestion.
- Basic schema validation.
- Heuristic scoring for three risk dimensions + total risk.
- Streamlit table, filters, chart, and single-game card.
- Basic unit tests.

## Out of scope in v1
- Crawlers / scraping.
- External APIs.
- Databases and user accounts.
- Causal claims or regulatory determinations.
